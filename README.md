# OSO — juego de Julia y JoseLuis

Juego "OSO" en un único HTML autocontenido (`index.html`), sin dependencias ni paso de build.

## Jugar en local

Abre `index.html` en el navegador, o sirve la carpeta:

```bash
python3 -m http.server 8000
```

## Despliegue

Sitio estático en Vercel (sin framework, sin build). Cada push a `main` se publica automáticamente.

## Versiones anteriores

`old-references/` guarda las versiones previas del juego como referencia. Están excluidas del despliegue mediante `.vercelignore`.
